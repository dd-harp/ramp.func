# Make parameters for an exponential function

Return an object to configure a function
[make_function.exp](https://dd-harp.github.io/ramp.func/reference/make_function.exp.md)

## Usage

``` r
makepar_F_exp(rate = -1, N = 1)
```

## Arguments

- rate:

  the rate parameter

- N:

  the length of the functions return value

## Value

an exponential F object
