# Make a Function that is the sum of Two other Functions

Build a function that is the sum of two other functions.

## Usage

``` r
# S3 method for class 'sum'
make_function(F_obj)
```

## Arguments

- F_obj:

  a function object,
  [F_obj](https://dd-harp.github.io/ramp.func/reference/F_obj.md)

## Value

a function that is the sum of two other functions
