# Make a Sigmoidal Function

Build a function to model a forced seasonal signal. The shape parameters
determine the timing, frequency, and relative intensity over the season.
The function is normalized to have an annual value set by `norm`

## Usage

``` r
# S3 method for class 'sigmoid'
make_F_t(F_obj)
```

## Arguments

- F_obj:

  a function object,
  [F_obj](https://dd-harp.github.io/ramp.func/reference/F_obj.md)

## Value

a function
