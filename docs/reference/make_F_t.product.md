# Make a Sinusoidal Function

Build a function that is the product of two other functions

## Usage

``` r
# S3 method for class 'product'
make_F_t(F_obj)
```

## Arguments

- F_obj:

  a function object,
  [F_obj](https://dd-harp.github.io/ramp.func/reference/F_obj.md)

## Value

a function that is the product of two other functions
